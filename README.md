# XRP Intelligence Feed — v0.1.1

Free, modular foundation for an XRP/XRPL intelligence feed.

## Current foundation
- Python 3.12+ compatible
- RSS collector abstraction
- NewsItem model and fingerprints
- JSON state/deduplication
- Discord webhook sender
- JSON configuration
- Pytest foundation
- GitHub Actions workflow

No paid API or AI service is required.

Source selection and intelligence scoring are intentionally not finalized yet; those will be researched before production collectors are locked in.
